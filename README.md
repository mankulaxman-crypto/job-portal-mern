MERN Stack Job Portal - Job Search, apply, admin panel with JWT Auth

A full stack job portal where users can search & apply for jobs, and admin can post jobs.

## Tech Stack
- MongoDB, Express.js, React.js, Node.js
- JWT Authentication
- Tailwind CSS

## Features
- User Login/Register
- Job Search & Filter
- Apply for Jobs
- Admin Panel to Post/Delete Jobs
- Responsive Design
